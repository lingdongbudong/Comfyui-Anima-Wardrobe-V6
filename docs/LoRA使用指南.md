## 一、三张速查表

### 1. 默认就用这套（90% 场景）

| LoRA | 权重 | 作用 |
|---|---|---|
| `anima-turbo-lora-v0.2` | **0.85** | 加速：16 步出图（关掉要 28 步，慢 30%） |
| `anima-base-1-light-concepts-v31` | **0.30** | 玻璃/水面/透光质感 |
| `anima-base-1-masterpiece-v51` | **0.60** | 细节增强，风格不变 ← **加上它最划算** |

- 采样：16 步 / CFG 2.0 / `er_sde` / `beta`
- 耗时：**34.1 秒**（2304×1296，含二采）
- 效果：平涂硬边保持不变，布料褶皱、发丝、玻璃高光明显更细，对比度从 69 升到 77

### 2. 想换画风（水彩）

| LoRA | 权重 | 备注 |
|---|---|---|
| `anima-turbo-lora-v0.2` | 0.85 | 保留 |
| `mona_watercolor_anima_v2` | **1.00** | **必须手填触发词 `@mona_watercolor`** |

- 采样不变（16 步 / CFG 2.0）
- 效果：纸白背景、未上色纸边、通透水痕；**人物身上的水彩笔触最明显**
- ⚠️ 权重 **1.3 会出现第二个人**（小球里复制一个自己），1.0 是上限
- ⚠️ 别再叠 masterpiece：实测叠 0.6 后水彩感消失，变成普通厚涂插画

### 3. 想换画风（水粉 / 极简海报）

| LoRA | 权重 | 必须同时改 |
|---|---|---|
| `gouache_AN2.9B_v1` | **0.80** | 关 turbo；28 步 / CFG **4.5** / `sgm_uniform` |

- 耗时：**42–44 秒**
- **必须用黑底/深色底场景**（`sc_art_black_*`、`*_black_keyhole`）。实测黑底出「黑底 + 白色光球剪影」，是这套里最像海报的一张
- ⚠️ **白底场景会吃掉主体**：主体缩到右下角，画面 3/4 是空白 —— 这是它「压平背景 + 负空间」的设计，不是崩图，但对人物特写是灾难
- ⚠️ **绝不能在 turbo 开启时用**：0.9 会崩成右侧一条竖带，0.5 会整片过曝发白

## 二、逐个说明

### `anima-turbo-lora-v0.2`｜加速器

| 项 | 内容 |
|---|---|
| 触发词 | 无 |
| 推荐权重 | **0.85**（0.7–0.9 均可） |
| 效果 | 把采样步数从 28 压到 16，速度约快 30% |
| 副作用 | 会与原版全量训练的 LoRA 冲突（见第三节） |
| 什么时候关 | 用 gouache 时必须关 |

这是**唯一一个「基础设施」型 LoRA**，不是风格也不是画质，是速度。它和大多数风格 LoRA 抢同一段采样轨迹，所以「turbo 开 + 全量训练 LoRA」是冲突的根源。

### `anima-base-1-masterpiece-v51`｜细节增强（最推荐）

| 项 | 内容 |
|---|---|
| 触发词 | `masterpiece, very aesthetic` |
| 推荐权重 | **0.60**（0.5–0.7） |
| 效果 | 布料褶皱、发丝分束、玻璃高光、材质区分度全部提升；**画风不变**，仍是平涂硬边 |
| 副作用 | **1.0 会崩**：球被推出画面、出现白色斑点、地上多出裂纹 |
| 训练信息 | 386 张全 masterpiece 图，多分辨率 1024/1280/1536，3 epoch |

**这是最安全的一档提升**。如果你只想动一个数字，就把它的开关打开、权重 0.6。

### `anima-base-1-light-concepts-v31`｜光学概念

| 项 | 内容 |
|---|---|
| 触发词 | `caustics` / `refraction` / `hue shifting` / `dispersion` / `subsurface scattering` / `translucent` / `bioluminescence` / `ultraviolet light` |
| 推荐权重 | **0.30**（默认）；想更亮的高光用 0.5–0.6 |
| 效果 | 玻璃、水面、皮肤透光更真实；0.6 时高光点更密更亮，整体亮度会降一档 |
| 副作用 | 权重越高整体越暗（0.3 → 亮度 191，0.6 → 173） |
| 关于触发词 | **实测作用很弱**：加 `caustics, hue shifting, refraction` 只造成 10% 像素变化，几乎看不出 |

它是个「概念 LoRA」不是「打光 LoRA」：不写触发词它也一直在轻微起作用（作为 0.3 的底色），写了触发词提升有限。**不要指望靠它做出华丽光效**，那要靠场景的 `extra` 或 `light_fx` 字段。

### `anima-highres-aesthetic-boost`｜高清美学

| 项 | 内容 |
|---|---|
| 触发词 | 无 |
| 推荐权重 | 0.5（**谨慎**） |
| 效果 | 细节确实增加（像素差 34.8%、亮度 191→182） |
| 副作用 | **实测出现「第二个玻璃球」**（画面左侧多一个球影）；叠 0.3 + masterpiece 0.6 会整体发平（对比度 58.7） |
| 结论 | **不建议和 masterpiece 同时用**。两者都做「细节」这件事，会互相干扰 |

✅ 已补为管理器**第 6 行**（默认关）。换 LoraManager 时曾整行漏搬，2026-11-05 已修复并验证出图正常。

### `mona_watercolor_anima_v2`｜水彩

| 项 | 内容 |
|---|---|
| 触发词 | **`@mona_watercolor`（必填）** |
| 推荐权重 | **1.00**（0.7–1.0） |
| 效果 | 纸白背景、颜料晕染、未上色纸边；人物也吃到水彩笔触 |
| 权重对照 | 0.7 → 只是通透柔和，水彩感弱；1.0 → 明显水彩；**1.3 → 出现第二人** |
| 兼容 turbo | ✅ 完全兼容，16 步 / CFG 2.0 直接用 |

**这是最省事的一档换风格**：不用改任何采样参数，开关一开就换画风。代价是它会重画整个画面，构图和细节都会变（水彩天然柔边，硬边平涂的锐利感会失去）。

### `gouache_AN2.9B_v1`｜水粉 / 平涂海报

| 项 | 内容 |
|---|---|
| 触发词 | `gouache`（元数据里出现 432 次，是该模型最高频词） |
| 推荐权重 | **0.80**（0.7–0.9） |
| 必需参数 | **关 turbo；28 步 / CFG 4.5 / `sgm_uniform`** |
| 效果 | 粉彩哑光色块、背景压成大面积纯色、大量负空间 → 极简海报 |
| 致命点 | **必须配深色底场景**。黑底 → 黑底白球剪影（很棒）；白底 → 主体缩成右下角一点（废） |
| 训练信息 | 432 张，学习率 5e-4 |

它和当前这套「白底硬光 + 主体占满」的构图逻辑**天然相反**。想用它，请换到 `bg=黑底逆光` 那一类场景，或者干脆接受「主体变小、留白变大」的海报感。

## 三、组合规则

### 能叠的组合（实测通过）

| 组合 | 合计权重 | 结果 |
|---|---|---|
| turbo 0.85 + light 0.3 | 1.15 | 基准，平涂硬边 |
| turbo 0.85 + light 0.3 + masterpiece 0.6 | **1.75** | ✅ **最佳。细节提升、风格不变** |
| turbo 0.85 + mona 1.0 | 1.85 | ✅ 水彩 |
| turbo 0.85 + gouache 0.35 + mona 0.7 | 1.90 | ⚠️ 柔和插画 + 太阳耀斑，好看但**已不是平涂** |

### 不能叠的组合（实测出问题）

| 组合 | 出什么问题 |
|---|---|
| masterpiece 1.0 | 构图崩、白色斑点、地面裂纹 |
| mona 1.3 | 出现第二个人 |
| mona 1.0 + masterpiece 0.6 | 水彩感被抹平，变成普通厚涂插画 |
| gouache + turbo（任意权重） | 0.9 → 崩成竖带；0.5 → 整片过曝 |
| gouache 0.8（白底场景） | 主体缩成右下角一点，3/4 画面空白 |
| highres 0.5 | 出现第二个玻璃球 |

### 两条硬规则

1. **权重总和控制在 2.0 以内。** 实测 2.0 出头就开始出问题（mona 1.3 + turbo 0.85 = 2.15 出第二人；mona 1.0 + masterpiece 0.6 + turbo 0.85 = 2.45 风格紊乱）。
2. **风格类 LoRA 只能开一个。** gouache 和 mona 同时开会互相打架（0.35 + 0.7 时还算能看，但画风漂移不可控）。

### 权重三档速记

| 权重 | 含义 |
|---|---|
| 0.3 | 「底色级」——轻微影响，不改变画面骨架 |
| 0.6 | 「标准级」——效果明确，仍受提示词控制 |
| 0.9–1.0 | 「主导级」——开始重画画风，容易压过场景设定 |
| >1.2 | 「危险级」——构图崩坏 / 分身 |

## 五、五个必须记住的坑

1. **turbo 与全量训练 LoRA 冲突**。turbo 是按「16 步能出图」蒸馏的；gouache 是按「28 步 / CFG 4.5」训练的。两者一起用，症状不是「风格变弱」而是**构图直接崩**（竖带、大留白、过曝）。换 gouache 一定先关 turbo、改三个参数。

2. **`@mona_watercolor` 要手填**。LoraManager 的触发词是自动前置的，但 mona 这条实测不填会弱一档。填在面板的 `extra_body` 里，会排在标签区最前。

3. **玻璃球类场景容易出第二人**。这是玻璃反射诱导的。mona 1.3、highres 0.5 都在这个场景下出过。**风格 LoRA 上新权重先在普通场景试，别直接上玻璃球。**

4. **masterpiece 的甜点区很窄**。0.6 最好，1.0 就崩。它不是「越高越精细」，而是「越高越容易推走构图」。

5. **`kaminarimon_v3` 是 Illustrious 架构**，放进 Anima 工作流不会报错，但会静默失效或污染画面。看 `base_model` 字段，不是 `Anima` 的一律不用。
